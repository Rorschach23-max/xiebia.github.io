# 页面滑动交互的实现

## 🎯 概述

本项目实现了一套完整的页面滑动交互系统，支持页面级别的区域切换（contentOne → contentTwo → contentThree）以及特定区域内的独立滚动，两者互不干扰。

## 🏗️ 整体架构

### 核心组成

- **CSS 吸附滚动**：基础的页面结构和滚动行为
- **usePageScroll Hook**：JavaScript 滚动事件处理和状态管理
- **区域隔离 Hooks**：特定区域的滚动事件隔离处理

## 📱 页面级滑动实现

### 1. CSS 布局基础

```less
// 页面容器：启用吸附式滚动
.pageContainer {
  height: 100vh;
  overflow-y: scroll;
  scroll-snap-type: y mandatory; // 强制吸附到指定位置
  scroll-behavior: smooth; // 平滑滚动效果

  // 隐藏滚动条，保持视觉简洁
  scrollbar-width: none;
  -ms-overflow-style: none;
  &::-webkit-scrollbar {
    display: none;
  }
}

// 每个内容区域都是全屏高度
.contentOne,
.contentTwo,
.contentThree {
  width: 100%;
  height: 100vh; // 关键：每个区域占满整个视口
  scroll-snap-align: start; // 吸附到视口顶部
}
```

**关键原理：**

- `scroll-snap-type: y mandatory` 强制滚动吸附到指定位置
- 每个区域高度为 `100vh`，确保一次滚动切换一个完整区域
- `scroll-snap-align: start` 让每个区域吸附到视口顶部

### 2. JavaScript 滚动控制

#### 核心状态管理

```typescript
const usePageScroll = () => {
  const [currentSection, setCurrentSection] = useState(0); // 当前区域索引
  const pageContainerRef = useRef<HTMLDivElement>(null); // 页面容器引用
  const isTransitioning = useRef(false); // 防抖标志
  const transitionTimer = useRef<NodeJS.Timeout>(); // 防抖定时器
};
```

#### 区域切换函数

```typescript
const scrollToSection = (sectionIndex: number) => {
  const container = pageContainerRef.current;
  if (container && !isTransitioning.current) {
    isTransitioning.current = true;

    // 计算目标滚动位置：区域索引 × 视口高度
    const targetScroll = sectionIndex * window.innerHeight;

    // 执行平滑滚动
    container.scrollTo({
      top: targetScroll,
      behavior: 'smooth',
    });

    // 设置防抖，800ms内禁止重复触发
    clearTimeout(transitionTimer.current);
    transitionTimer.current = setTimeout(() => {
      isTransitioning.current = false;
    }, 800);
  }
};
```

**设计要点：**

- **防抖机制**：防止用户快速操作造成的动画混乱
- **位置计算**：`targetScroll = sectionIndex × window.innerHeight`
- **平滑动画**：使用原生的 `scroll-behavior: smooth`

### 3. 多种输入方式支持

#### 🖱️ 鼠标滚轮

```typescript
const handleWheel = (e: WheelEvent) => {
  if (isTransitioning.current) return; // 防抖检查

  e.preventDefault(); // 阻止默认滚动行为

  if (e.deltaY > 0 && currentSection < 2) {
    // 向下滚动：切换到下一区域
    scrollToSection(currentSection + 1);
  } else if (e.deltaY < 0 && currentSection > 0) {
    // 向上滚动：切换到上一区域
    scrollToSection(currentSection - 1);
  }
};
```

## 🔒 特定区域滚动隔离

### 核心挑战

在 contentThree 区域中，文档列表和文档查看器需要独立滚动，但不能影响整体的页面切换。

### 解决方案：事件捕获 + 位置检测

#### 1. 实时鼠标位置检测

```typescript
const isMouseInDocListArea = (e: MouseEvent | WheelEvent) => {
  const rect = docListContainer.getBoundingClientRect();
  return (
    e.clientX >= rect.left &&
    e.clientX <= rect.right &&
    e.clientY >= rect.top &&
    e.clientY <= rect.bottom
  );
};
```

**原理：**

- 实时获取容器的边界位置 `getBoundingClientRect()`
- 检查鼠标坐标是否在容器范围内
- 只有在特定区域内才处理滚动事件

#### 2. 事件捕获与阻止传播

```typescript
const handleDocumentScroll = (e: WheelEvent) => {
  // 只有鼠标在目标区域内才处理
  if (isMouseInDocListArea(e)) {
    e.stopPropagation(); // 阻止事件向上冒泡
    e.preventDefault(); // 阻止默认滚动行为

    // 手动处理区域内滚动
    const { scrollTop, scrollHeight, clientHeight } = docListContainer;
    const maxScroll = scrollHeight - clientHeight;

    if (maxScroll > 0) {
      const scrollDelta = e.deltaY;
      const newScrollTop = Math.max(0, Math.min(maxScroll, scrollTop + scrollDelta));
      docListContainer.scrollTop = newScrollTop;
    }
  }
};

// 在document级别监听，使用捕获阶段优先处理
document.addEventListener('wheel', handleDocumentScroll, {
  passive: false, // 允许preventDefault
  capture: true, // 捕获阶段，优先级最高
});
```

**关键技术点：**

1. **捕获阶段监听**（`capture: true`）

   - 事件传播顺序：捕获 → 目标 → 冒泡
   - 在捕获阶段优先处理，确保特定区域滚动优先级最高

2. **手动滚动计算**

   - 完全接管滚动逻辑，精确控制滚动距离
   - 边界检查：`Math.max(0, Math.min(maxScroll, newScrollTop))`

3. **事件阻止**
   - `stopPropagation()`：防止事件继续传播到页面级滚动处理器
   - `preventDefault()`：阻止浏览器默认滚动行为

#### 3. 触摸设备支持

```typescript
const handleTouchMove = (e: TouchEvent) => {
  const touchY = e.touches[0].clientY;
  const deltaY = lastTouchY - touchY;
  lastTouchY = touchY;

  e.stopPropagation();

  }
};
```

## 🎛️ 滚动状态监听

```typescript
const handleScroll = () => {
  clearTimeout(scrollTimer);
  scrollTimer = setTimeout(() => {
    const scrollTop = container.scrollTop;
    const sectionHeight = window.innerHeight;
    // 根据滚动位置计算当前区域
    const currentIndex = Math.round(scrollTop / sectionHeight);
    setCurrentSection(Math.max(0, Math.min(2, currentIndex)));
  }, 50); // 50ms 防抖，平衡响应速度和性能
};
```

**状态同步：**

- 监听容器的实际滚动位置
- 通过 `scrollTop / sectionHeight` 计算当前区域
- 使用防抖减少状态更新频率

## 📊 性能优化策略

### 1. 防抖机制

- **页面切换防抖**：800ms，确保动画完成
- **状态更新防抖**：50ms，平衡响应速度和性能
- **滚动事件防抖**：避免频繁计算和状态更新

### 2. 事件监听优化

- 使用 `passive: false` 仅在必要时，允许 preventDefault
- 及时清理事件监听器，避免内存泄漏
- 合理使用捕获阶段，避免不必要的事件处理

### 3. DOM 操作优化

- 缓存 DOM 元素引用（useRef）
- 减少重复的边界计算
- 使用原生 scrollTo API，避免复杂的动画库

## 🔧 技术总结

### 核心技术栈

- **CSS Scroll Snap**：现代浏览器原生吸附滚动
- **React Hooks**：状态管理和事件处理
- **事件捕获机制**：精确的事件处理优先级控制
- **几何计算**：实时位置检测和滚动计算

### 设计模式

- **单一职责**：每个 Hook 负责特定的滚动逻辑
- **事件代理**：在更高层级统一处理事件
- **状态集中管理**：当前区域状态的统一管理
- **防抖模式**：避免频繁操作的性能问题

这套滑动交互系统既保证了整体页面的流畅导航体验，又确保了局部区域的独立滚动功能，是一个完整且实用的前端交互解决方案。
